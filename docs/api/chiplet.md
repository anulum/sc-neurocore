# Chiplet Generator

Multi-die chiplet generator with UCIe/BoW die-to-die links.
Includes inter-die topology, thermal modelling, and yield estimation.

## Quick Start

```python
from sc_neurocore.chiplet.chiplet_gen import (
    ChipletGenerator, InterconnectTopo, ThermalModel, YieldEstimator,
)
```
